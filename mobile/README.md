# MomPopCare Mobile

This is the Sprint 2 Expo prototype for the first MomPopCare vertical slice.

## Status

Initialized for Sprint 2: First Vertical Slice.

## Prototype Scope

- Add a loved one.
- Add a care task.
- See attention-relevant tasks on Home.
- Complete a task.
- See completion reflected as recent activity.

## Data Lifetime

Data is stored in memory for this prototype and resets when the app reloads or restarts.

## Out of Scope

- backend services
- authentication
- production persistence
- Supabase
- AI
- notifications
- health tracking
- granular permissions
