# MomPopCare

MomPopCare is a family care coordination platform focused on reducing the cognitive load of caregiving so families can confidently understand what has been done, what is pending, and what needs attention. It is not an AI doctor, not a diagnosis app, not a generic health tracker, and not a document storage app.

## Current Status

Sprint 1 — Domain Discovery.

## Repository Structure

- `docs/`: product, decision, architecture, and sprint documentation
- `docs/adr/`: architecture decision records
- `docs/sprints/`: sprint planning and backlog documents
- `mobile/`: reserved for the future mobile application
- `backend/`: reserved for future backend services
